# Memory Game
This is a simple holiday-themed memory game that I built with the cmu_graphics library that uses python.
It has a 2x8 rectangle grid with 8 cards, 4 pairs, and when you get all the pairs finished it plays victory tunes.

### How to run:
To play, download and unzip the release and click on the .bat file if you use windows, or the .sh file if you use linux. If that fails, install cmu_graphics inside a python venv, get cmu_graphics, and run main.py.
